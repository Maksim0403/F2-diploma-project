## Архітектурний контекст

Система Pet Care System призначена для підтримки процесів догляду за домашніми тваринами. Архітектура передбачає Android-клієнт та три серверні мікросервіси: Pet Service, Reminder Service і Geo Service.

Pet Service використовує Event Sourcing для збереження історії змін даних про тварин. Для міжсервісної взаємодії передбачено Apache Kafka та патерн Transactional Outbox.

Архітектурні рішення документуються у форматі ADR, а вимоги та діаграми підтримуються у Markdown безпосередньо в Git-репозиторії за принципом Docs-as-Code.
