## ⚙️ Нефункціональні вимоги (NFR Matrix)

| Категорія | Показник | Цільове значення |
|---|---|---|
| Продуктивність | Навантаження на API | до 100 RPS |
| Продуктивність | Прийом геопозицій | до 200 повідомлень/с |
| Продуктивність | Latency API, p95 (читання з проєкцій) | ≤ 200 мс |
| Продуктивність | Latency API, p95 (команда із записом події) | ≤ 400 мс |
| Продуктивність | Затримка від вимірювання до сповіщення про перетин зони, p95 | ≤ 3 с |
| Продуктивність | Лаг проєкцій, p95 | ≤ 1 с |
| Якість | Частка хибних спрацювань геозон (шум GPS ≤ 30 м) | ≤ 5 % |
| Безпека | Автентифікація | JWT: access ≤ 15 хв, refresh ≤ 30 діб з ротацією; RBAC |
| Безпека | Відповідність | OWASP API Security Top 10, OWASP MASVS L1, GDPR |
| Надійність | Доставка подій | Transactional Outbox, ідемпотентні споживачі, Dead Letter Topic |
| Якість коду | Покриття модульними тестами доменної логіки | ≥ 70 % |
